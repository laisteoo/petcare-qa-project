# PetCare QA Documentation

This folder contains the quality assurance documentation for the PetCare appointment scheduling application.

## Project Overview

The project focuses on manual QA activities for a web application used to manage pet profiles and appointment scheduling.

## Testing Documentation

- [Test Cases](Test%20Cases.md) — scenarios, preconditions, test steps, expected and actual results, and status.
- [Bug Reports](Bug%20Reports.md) — documented defects, severity, priority, reproduction steps, and Jira references.
- [Exploratory Testing](Exploratory%20Testing.md) — exploratory charters, actions performed, observations, and outcomes.
- [Download the Excel workbook](PetCare_QA_Test_Documentation_EN.xlsx) — complete spreadsheet version of the test documentation.

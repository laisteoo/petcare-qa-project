# QA Documentation

This folder contains the quality assurance documentation for the PetCare appointment scheduling application.

## Testing Activities

- Manual testing
- Test case design and execution
- Exploratory testing
- Bug reporting and documentation

## Test Management

Test cases, exploratory testing records, bug reports, and supporting evidence are managed in Jira and the project's test documentation spreadsheet.
